Lyria RealTime 是什麼？

Google 提供的即時音樂生成 API，透過 WebSocket 連線實現低延遲的串流音樂輸出。

項目規格
模型名稱models/lyria-realtime-exp
連線方式WebSocket（雙向即時通訊）
輸出格式16-bit PCM, 48kHz 立體聲
延遲最多 2 秒
音樂類型以純器樂為主
💡 適用場景：遊戲配樂（根據玩家行為即時變換）、互動裝置（展覽 / 藝術裝置）、即時 DJ 應用（文字操控音樂轉換）。

取得 API 金鑰 + 安裝套件

1

前往 Google AI Studio 取得金鑰

前往 Google AI Studio，點擊 Get API Key 按鈕建立你的 API 金鑰。

2

安裝 Python 套件

pip install google-genai
⚠️ 安全提醒：API 金鑰等於密碼，不要公開分享！截圖時要馬賽克遮住金鑰內容。建議使用環境變數或 .env 檔案管理。

每個步驟的對應選項

🎸

M - Mood 情緒

8 種情緒選項：快樂、悲傷、活力充沛、平靜放鬆、史詩壯闘、浪漫溫馨、神秘懸疑、憤怒激烈

🎹

I - Instrument 樂器

8 種樂器組合：鋼琴、吉他、弦樂、電子合成器、管樂、打擊樂、混合樂團、極簡配置

🎤

V - Vocal 人聲

5 種選項：無人聲（純器樂）、男聲、女聲、合唱團、哼唱

🎧

D - Dynamic 動態

5 種動態：漸強、漸弱、穩定、起伏交替、爆發

🎶

S - Style 風格

10 種風格：流行、搖滾、爵士、古典、電子、R&B、嘻哈、民謠、電影配樂、Lo-fi

⏱

T - Tempo 節奏

自訂 BPM (40-200) + 6 種預設：很慢60、慢速80、中速100、稍快120、快速140、很快160

程式碼重點解說

1. 選單資料結構

每個選項是一個 tuple：("顯示名稱", "給 AI 的英文提示詞")

# 情緒選單範例
MOOD_OPTIONS = [
    ("快樂歡愉", "happy, joyful, uplifting"),
    ("悲傷感性", "sad, melancholic, emotional"),
    ("活力充沛", "energetic, powerful, driving"),
    ("平靜放鬆", "calm, relaxing, peaceful"),
    # ...
]

2. WeightedPrompt 權重設定

不同類別的提示詞有不同權重，讓 AI 更精準理解重點：

# 各類別權重
weighted_prompts = [
    WeightedPrompt(text=style_prompt,  weight=1.0),  # 風格最重要
    WeightedPrompt(text=vocal_prompt,  weight=0.9),  # 人聲次之
    WeightedPrompt(text=mood_prompt,   weight=0.8),  # 情緒第三
    WeightedPrompt(text=instr_prompt,  weight=0.6),  # 樂器輔助
]

3. 生成參數設定

config = LiveConnectConfig(
    response_modalities=["AUDIO"],
    output_audio_transcription=AudioTranscriptionConfig(),
    realtime_input_config=RealtimeInputConfig(
        automatic_activity_detection=AutomaticActivityDetection(disabled=True)
    ),
    music_generation_config=MusicGenerationConfig(
        bpm=user_bpm,              # 使用者設定的節拍
        temperature=1.0,           # 創意度（0-2，越高越有創意）
        weighted_prompts=prompts   # 加權提示詞組合
    )
)
💡 小知識：temperature 值越高，生成的音樂越有創意和變化；越低則越穩定可預期。建議從 1.0 開始嘗試。

免費試玩工具

除了自己寫程式，Google 也提供了幾個現成的工具讓你體驗 Lyria RealTime 的威力：

🎷

Prompt DJ

AI Studio 網頁版即時 DJ，用文字操控音樂風格轉換，最簡單的入門方式，打開瀏覽器就能玩！

難度：⭐ 最簡單

aistudio.google.com/apps/bundled/promptdj

🎹

MIDI DJ

外接 MIDI 控制器，透過 Chrome 瀏覽器的 Web MIDI API 即時操控音樂生成，適合有 MIDI 設備的使用者。

難度：⭐⭐ 中等

需求：MIDI 控制器 + Chrome 瀏覽器

🎧

The Infinite Crate

免費 VST 外掛，可以直接在 DAW（數位音訊工作站）中使用，適合專業音樂製作人。

難度：⭐⭐⭐ 進階

magenta.withgoogle.com/infinite-crate

💡 建議路線：先玩 Prompt DJ 體驗即時操控的感覺 ➔ 再嘗試寫 Python 程式自訂更多參數 ➔ 最後用 Infinite Crate 整合到你的音樂製作流程中。
