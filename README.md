# Gemini 音樂生成術：從零開始的 AI 作曲完整教學

> 不需要懂樂理、不需要會樂器，只要會說話就能作曲！

## 課程簡介

2026 年 2 月，Google 在 Gemini App 中正式推出 Lyria 3 音樂生成模型。本教學涵蓋四種 AI 音樂生成方式，從入門到實戰。

## 教學內容

| Part | 主題 | 說明 |
|------|------|------|
| Part 1 | 前言與事前準備 | Lyria 3 介紹、帳號設定、訂閱方案 |
| Part 2 | 文字生成音樂 | 自然語言描述，AI 即時作曲 |
| Part 3 | 圖片生成音樂 | 上傳照片，AI 感知情緒自動配樂 |
| Part 4 | Gem 機器人 | 打造專屬音樂提示詞產生器 |
| Part 5 | API 開發者玩法 | Lyria RealTime API + 互動式程式 |
| Part 6 | 提示詞攻略 | MIDST 公式、中英對照表 |
| Part 7 | 實戰與 FAQ | SynthID、五種情境、常見問題 |
| Part 8 | 課程認證測驗 | 20 題隨機抽 10 題、80 分通過取得證書 |

```

├── 參考.md                        # 參考資料連結
├── README.md                      # 本檔案
└── 簡報/                          # HTML 簡報

    ├── Part2_文字生成音樂.html
    ├── Part3_圖片生成音樂.html

    ├── Part5_API開發者玩法.html
    ├── Part6_提示詞攻略.html
    ├── Part7_實戰與FAQ.html
    └── Part8_認證測驗.html
```

## 使用方式

1. 開啟 `簡報/index.html` 進入課程總覽
2. 點擊各 Part 進入投影片簡報
3. 搭配 `Gemini音樂生成術_完整教學.md` 閱讀完整文字教學
4. 使用 `generate_music.py` 體驗 API 音樂生成
