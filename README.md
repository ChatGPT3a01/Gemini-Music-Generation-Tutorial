## 📌 課程簡介

Google 在 Gemini App 中正式推出 **Lyria 3** 音樂生成模型。本課程將帶你完整掌握 **四種 AI 音樂生成方式**，從入門到實戰，一步步成為 AI 作曲高手。

```
你想用 AI 做什麼音樂？
│
├─► 用文字描述 ──────────► Part 2 文字生成音樂
│
├─► 用照片配樂 ──────────► Part 3 圖片生成音樂
│
├─► 用 Gem 機器人輔助 ───► Part 4 Gem 機器人
│
└─► 用程式即時生成 ──────► Part 5 API 開發者玩法
```

### 🔰 基礎篇

- 📌 **Part 1** — 前言與事前準備

  - 自然語言描述，AI 即時作曲

  - 上傳照片，AI 感知情緒自動配樂

  - 浮水印解析、五種情境、常見問題

1. 開啟 `簡報/index.html` 進入課程總覽
2. 輸入課程密碼進入簡報

4. 完成 Part 8 認證測驗取得證書
